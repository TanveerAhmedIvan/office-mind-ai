OfficeMind AI: how it works

RAG chatbot for Nodi Tech Ltd. Answers only from data/, cites sources, refuses otherwise. Stack: bge-m3 embeddings, local Qdrant, BM25, bge-reranker-v2-m3, Qwen2.5-3B via Ollama, FastAPI + SSE, plain HTML UI. CPU only on the office PC.

0. System map

1. Indexing (run once, or after data/ changes)

1

Parse and chunk

Fileapp/ingest.py ingest_all(), chunk_markdown(), chunk_pdf() Readsevery .md and .pdf in data/ (12 files) DoesSplits by heading (max 1200 chars). Keeps tables whole. PDF tables become markdown and are excluded from prose. Drops injection lines (sanitize()), detects Bangla vs English, flags files marked SUPERSEDED. OutputChunk(id, source, section, text, superseded, lang, flagged) in memory
↓
2

Embed and store vectors

Fileapp/vector.py build_index(). Command: python -m app.vector build Readschunks from step 1; model BAAI/bge-m3 (HuggingFace cache) Writesqdrant_data/ (collection nodi_docs, cosine, chunk fields as payload)
↓
3

BM25 index

Fileapp/hybrid.py _bm25() Readschunks re-parsed from data/ at first query WritesRAM only (lost on restart, rebuilt in about a second). Codes like ND-1042 are kept whole.

2. One chat message, step by step

1

Receive message and load session

Fileapp/server.py chat(), app/sessions.py SessionStore.history() ReadsJSON {message, session_id} from the browser. History (last 6 turns) from SQLite chat_data/sessions.db; new uuid if none. SessionStored on disk, so it survives a restart. Chats unused for 30 days are purged at startup (SESSION_TTL_DAYS). The browser holds only the id in a JS variable (restored after a page reload via localStorage and GET /sessions/{id}).
↓
2

Input guard

Fileapp/chat.py guarded_answer() DoesRegex LEAK catches "system prompt", "ignore previous instructions", etc. and returns a fixed refusal with no LLM call.
↓
3

Rewrite follow-up LLM call 1

Fileapp/chat.py rewrite() Readssession history plus the new message DoesSkipped when history is empty. Otherwise asks Qwen (temp 0) for a standalone question, e.g. "and for sick leave?" becomes "How many sick leave days per year?"
↓
4

Vector search (top 20)

Fileapp/vector.py search() Readsqdrant_data/; embeds the query with bge-m3
↓
5

BM25 search (top 20)

Fileapp/hybrid.py bm25_search() Readsin-RAM BM25 index (exact words and codes)
↓
6

Fuse and rerank

Fileapp/hybrid.py rrf(), hybrid_search() DoesReciprocal rank fusion (k=60), keeps 16 candidates, cross-encoder bge-reranker-v2-m3 rescoring, score x0.5 for superseded chunks, returns top 5. Costabout 4 s on the dev CPU; the largest retrieval cost
↓
7

Build fenced prompt

Fileapp/chat.py build_messages(), SYSTEM_PROMPT DoesSystem rules, then trimmed history, then the user turn with the 5 chunks inside <context><doc source=… superseded=…>. Context is declared untrusted data.
↓
8

Generate and stream LLM call 2

Fileapp/llm.py OllamaLLM.chat(), then app/server.py sse() ReadsOllama at localhost:11434, model qwen2.5:3b SendsSSE events meta (sources, chunk ids and scores, standalone question), many token, then done.
↓
9

Save turn

Fileapp/server.py gen(), SessionStore.append_turn() WritesInserts the user and assistant messages into chat_data/sessions.db and deletes rows older than the last 6 turns for that session.
